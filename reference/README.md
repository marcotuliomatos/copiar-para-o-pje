# Referência de origem

`Copiar_para_o_PJe_v0.8.4.oxt` é o pacote original recebido, preservado byte a byte. `SHA256SUMS` permite conferir sua integridade (`sha256sum -c reference/SHA256SUMS` a partir da raiz do projeto). A árvore `extension/` foi extraída dele sem alterações.

O ZIP original contém Basic/XML, configurações UNO, recursos e um JAR Java sem fonte. Os metadados de autoria e `icons/NOTICE.txt` foram preservados. O pacote não apresenta uma licença geral explícita; este repositório não concede licença por conta própria. A decisão de licenciamento e eventual publicação fica com o mantenedor. O ícone não é a logomarca vetorial oficial do CNJ, conforme o aviso original.
