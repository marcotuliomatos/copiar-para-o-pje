# Pendências e possíveis melhorias

Este arquivo é uma lista de trabalho, não uma autorização para implementar tudo. Priorize conforme bugs reproduzidos e decisões do mantenedor.

- [ ] Validar v0.8.4 no PJe real, especialmente o incidente de vazio antes de `4)`; registrar evidências sintéticas.
- [ ] Ampliar a suíte UNO: seleção, estilos efetivos, links, listas, tabelas, imagens, limites e falhas.
- [ ] Testar atomicidade do clipboard e comportamento em caso de falha após conversão; verificar formatos e listener em sessão gráfica.
- [ ] Recuperar fonte Java original e processo de compilação reproduzível. Até lá, preservar o JAR.
- [ ] Definir licença geral e condições de redistribuição com o mantenedor, preservando créditos e direitos de terceiros.
- [ ] Se necessário, adicionar matriz de compatibilidade baseada em versões realmente testadas.

Não introduzir dependências de runtime, telemetria, reformulação arquitetural, publicação ou integração automática com o PJe apenas por conveniência.
